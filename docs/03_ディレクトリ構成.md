# 03 ディレクトリ構成

## `routes/`

- URL と controller を紐づける

## `controllers/`

- リクエストを受ける
- service を呼んで返す

## `services/`

- 一覧/詳細ごとの返却形を組み立てる

## `repositories/`

- データ取得元を隠蔽する
- Mock API のエラーをドメイン向けに変換する

## `clients/`

- 外部 HTTP 通信を担当する

## `models/`

- Flutter へ返す項目名と形式を定義する

## `middlewares/`

- リクエストログとエラーレスポンスを扱う
