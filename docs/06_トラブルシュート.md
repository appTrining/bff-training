# 06 トラブルシュート

## WireMock未起動

- `mock-training` が起動しているか確認する
- `MOCK_API_BASE_URL` を確認する
- `curl http://localhost:8080/mock/news` で直接確認する

## 404になる

- BFF は `news_001` を受けても Mock へは `news-001` で取りに行く
- 対象 ID が `mock-training` にあるか確認する

## 500になる

- Mock 側の `mode=error` などのエラー定義を確認する
- BFF が `MOCK_API_ERROR` へ変換して返しているか確認する
